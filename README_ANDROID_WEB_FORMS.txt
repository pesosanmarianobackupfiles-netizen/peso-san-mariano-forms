PESO SAN MARIANO - ANDROID WEB FORMS

This package is a TRUE WEBSITE version of the three forms.
It does NOT require PWA installation and does NOT use a service worker.

Folders:
  /nsrp/              NSRP Jobseeker Registration Form
  /monthly-rice/      Monthly Rice Distribution Form
  /field-monitoring/  PESO Field Monitoring Report

HOW TO MAKE IT PUBLIC:
1. Upload the contents of this folder to a static web host such as GitHub Pages, Netlify, Cloudflare Pages, or your LGU/PESO web server.
2. Make sure the website uses HTTPS.
3. Open the website URL on Android Chrome/Edge.
4. The portal QR code automatically encodes the actual website URL.
5. Each form also has its own QR code that encodes its current URL.

IMPORTANT:
- localhost is only the computer itself. Android cannot open the PC's localhost.
- For public Android access, the files must be hosted on a real web address.
- No Install App button is included.
- The forms remain normal browser web forms.
- PDF/print functions still use the libraries included/referenced by the original forms.
